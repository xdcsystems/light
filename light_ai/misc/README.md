# misc/ — некоммитимые артефакты light_ai

Каталог игнорируется корневым .gitignore (правило misc/). Сюда складываются
файлы, которые не должны попадать в репозиторий, но которые жалко держать
в корне или удалять совсем.

## Содержимое

- rknn_toolkit_lite2-2.5.0-cp39-cp39-manylinux_2_17_aarch64.manylinux2014_aarch64.whl
  Офлайн-установщик rknn-toolkit-lite2 2.5.0 (aarch64, cp39). Единственный
  локальный источник для пересоздания venv на борде:
  pip install rknn_toolkit_lite2-2.5.0-...whl

- yolov5s_relu_int8.rknn
  Первая INT8-сборка от 24.10. Полностью пережита v2; хранится как история.

- yolov5s_relu_int8_mmse.rknn
  Экспериментальная INT8-сборка с MMSE-квантизацией от утра 26.10.
  Проиграла по качеству обычной v2, собранной через 4 минуты после неё.

## Рабочие модели (остались в корне light_ai)

- yolov5s_relu.rknn        — FP32-эталон точности (бейслайн M2.1)
- yolov5s_relu_int8_v2.rknn — валидированная INT8-сборка (26.10), откат
- yolov5s_relu_int8_mmse.rknn / yolov5s_relu_int8_mmse_v2.rknn —
  рабочая модель 30.10 -> 01.11, вытеснена v5
- yolov5s_relu_int8_v3.rknn — mmse, калибровка от 26.10 (записи о сборке
  расходятся; актуальна запись M2.4: дневные кадры, шкала 1/255)
- yolov5s_relu_int8_v4.rknn — mmse на дневном дампе 960p (dataset_day3)
- yolov5s_relu_int8_mmse_v5.rknn — РАБОЧАЯ модель с 01.11 (mmse на
  смешанном наборе: 30 ночных + 20 дневных кадров); она же — встроенный
  дефолт пайплайна (Config::model, см. README, раздел Defaults)
